# 玄枢 · 八荒编修台 1.1.4

依据旧版反编译源码，并参考 F8 修改器、大鬼工具盒和用户提供的大鬼编辑器源码重新实现。0.7 同时包含安全存档副本编辑和游戏内 Bridge 实时连接。

## 当前已经实现

- 自动发现并读取最新本机存档，支持旧版 `.cache` 与 JSON。
- 属性、已有功法境界、完美参悟、词条生效、已有好感、形象 ID、壶妖已有标量、宗门已有字段修改。
- 先天气运、后天气运、逆天改命、道心四个独立栏目，支持按 ID/名称搜索和添加、替换、删除。
- 性格、爱好、关系、道心、身份五个属性栏目；支持对主角好感、道种、阶段、境界、神魂、性别、发展方向、天骄和道号。
- 关系双向添加：好友、父母/子女/私生子女、兄弟姐妹、义亲、夫妻、道侣、师徒；好友表格支持普通单击累积多选、再次单击取消，以及批量添加、批量删除和批量解除好友。
- 一键流派包含剑、刀、拳、掌、指、枪六大体系的纯系、火、水、雷、土共 30 套攻略模板。
- 启动后读取 GitHub Releases 最新版本；发现更新时只询问是否打开下载页，不静默下载或替换程序。
- 普通物品新增和数量修改。复杂装备、随机词条装备暂不创建。
- 修改预览、全部撤销、导出副本、原文件字节备份和防覆盖保护。
- 自动识别 `ModExportData` 目录，并标记 F8 修改器和大鬼工具盒参考目录。
- `GGBH.BridgeMod.dll` 游戏客户端和本机命名管道服务端。
- 游戏内读取状态、读取当前人物、补满状态、白名单基础属性修改。
- 实时页同时显示基础值和游戏显示值，写入只使用基础值，避免功法/气运加成被重复叠加。

## 使用方式

1. 将配套 `GGBH.BridgeMod.dll` 放入游戏 `Mods` 目录，重启游戏。
2. 启动工作台和游戏，进入世界后打开“实时连接”页读取当前人物。
3. 实时修改必须点击“引用修改”才会写入游戏。
4. 存档修改默认只改内存副本；检查“修改预览”后导出到新文件，原文件不会被覆盖。
5. 好友多选：进入“关系 → 好友”，直接逐行单击即可累积选择，不需要按 Ctrl；再次单击可取消，最后点击“批量解除好友”。
