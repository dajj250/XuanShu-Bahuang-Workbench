# 玄枢八荒编修台 1.1.6 · 自动注入优化版

构建：`1.1.6-inject.2`。本次仅发行程序包，不附程序源码。

## 下载

- **XuanShu-Workbench-Server-v1.1.6.zip**：工作台、配套 DLL、使用指南及校验说明。解压整个压缩包后运行 EXE。
- **XuanShu-Legacy-Download-v1.1.6.zip**：旧版升级入口。运行后自动查找 1.1.6 或更新工作台并打开下载链接；不再创建旧版通信管道。

## 使用

1. 退出所有旧玄枢工作台，停用旧玄枢客户端 Mod，然后完整重启游戏。
2. 保留现有 MelonLoader；本版不需要安装玄枢官方客户端 Mod。
3. 运行工作台，默认自动检测单个鬼谷进程，等待约 20 秒后加载配套 DLL。
4. 在实时连接页确认 `1.1.6 优化版（inject.2）握手成功`；进入备份测试存档后读取人物。

错误 231 表示通信管道被其他实例占用，请只运行一个工作台。旧版升级入口需由使用者替换旧 EXE，无法远程改写已经分发的旧程序。

## 本次优化

- 修复注入入口执行后主线程桥接未启动的接入方式，保留原加载器回调。
- 独立通信通道、配套构建握手检查、自动注入开关、一次尝试限制。
- 增加入口、首次游戏帧、主线程启动与握手诊断；减少正常等待时的重复日志。
- 请求超时、心跳、断线结果结算及 DLL 哈希校验。

## 验证范围

58 项 Python 测试及独立帧接口转发测试通过；本机实测已观察到主线程接入、握手和游戏状态查询成功。当时游戏停在主菜单，人物查询返回预期的 `WORLD_NOT_READY`。

最终包的完整重启自动注入复测、角色写入、保存重载及所有 Mod 组合尚未验收。这仍是测试性质构建，请使用备份存档。
